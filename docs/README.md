# Documentation

This folder contains detailed documentation about the codebase.

## Files

- `structure.md` - Detailed directory and file structure
- `app.md` - Documentation for the app directory (routes, layouts, etc.)
- `components.md` - Documentation for reusable components
- `lib.md` - Documentation for utility functions and libraries
- `db.md` - Documentation for database schema and migrations
- `hooks.md` - Documentation for custom React hooks
- `actions.md` - Documentation for server actions
- `types.md` - Documentation for TypeScript type definitions

Each file provides an overview and details about the respective part of the codebase.
